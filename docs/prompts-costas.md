# Prompts das fotos de costas — MM Modas

## Como usar (importante)

1. Abra a **mesma conversa** em que você gerou a foto frontal (ou uma nova, anexando a foto frontal aprovada).
2. Anexe a **foto frontal aprovada** daquela peça e cole o prompt de costas do produto.
3. Nos produtos com **mascote grande nas costas** (camisetas, regata, polo, camisas, moletons, suéter e jaqueta jeans; marcados com "Mascote" no título), anexe também o `mascote-fundo-branco.png`.
4. Salve com o nome indicado (termina em `-costas.jpg`) em `public/produtos/`.
5. Para as outras cores, repita com a foto frontal de cada cor. O prompt é o mesmo.

## Prompt rápido (serve para qualquer peça)

```
Using the attached photo as reference, create the BACK view of this exact same garment, as if I turned it over. Show the back with its natural details, plain and with nothing printed (for pieces with a big back logo, use the product prompt below instead). Keep exactly the same garment, same color, same fabric texture, same background color, same soft studio lighting, same top-down flat lay framing and same 4:5 vertical size as the attached front photo. No people, no mannequin, no text, no watermark.
```

Peças sem versão de costas: meias, gorro, bucket hat e óculos, porque a foto frontal já mostra a peça inteira.
